# RX_ONLY Policy

Este proyecto es de observación pasiva únicamente. No se permite ninguna operación de transmisión ni manipulación activa.

- no transmisión
- no jamming
- no spoofing
- no deauth
- no takeover
- no localización de pilotos
- no decodificación de comunicaciones privadas
- solo observación pasiva
- dashboard local únicamente

El objetivo es mantener el sistema legalmente prudente y centrado en detección mínima y alertas locales.
