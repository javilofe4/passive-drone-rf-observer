# Seguridad y límites legales

Este proyecto está diseñado para observación pasiva únicamente. No debe utilizarse para interferir ni manipular comunicaciones.

- No transmitir.
- No realizar jamming, spoofing, deauth o takeover.
- No decodificar payloads privados.
- No almacenar datos personales ni payloads.

El usuario es responsable de comprobar la regulación local antes de operar receptores o antenas.
